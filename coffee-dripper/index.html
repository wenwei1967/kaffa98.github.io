先看懂濾杯的四個關鍵

濾杯的差異不只是造型。內部肋骨決定排氣與濾紙貼合程度；底部形狀影響粉層厚度；孔洞控制排水阻力；濾紙則進一步改變流速與口感。

形狀圓錐、平底或梯形，決定粉層分布。
肋骨螺旋、直立、短肋或花瓣，影響排氣。
孔洞單孔、三孔或多孔，改變流速限制。
濾紙錐形或波浪紙，改變貼壁與液體路徑。
DRIPPER GUIDE

Hario V60

圓錐形｜單一大孔｜螺旋肋骨

內部結構

肋骨由底部延伸至上緣，讓濾紙與杯壁之間保留空氣通道。大孔設計不主動限制流速，萃取速度主要由研磨、注水與粉層控制。

風味傾向

香氣奔放、酸質清晰、層次感強。適合淺焙與希望凸顯產區特色的咖啡。

技巧自由度高，但對注水穩定度較敏感。
DRIPPER GUIDE

Kalita Wave

平底形｜三孔｜短肋骨

內部結構

平坦底部讓咖啡粉層厚度較一致，三孔排水搭配波浪濾紙，降低濾紙貼壁造成的阻塞。

風味傾向

甜感明顯、口感圓潤、萃取均衡。

容錯率高，適合初學者與多人份穩定沖煮。
DRIPPER GUIDE

ORIGAMI

圓錐形｜單孔｜深直肋骨

內部結構

大量垂直肋骨形成寬闊排氣通道，可搭配錐形或波浪濾紙，改變粉層與流速。

風味傾向

錐形紙偏明亮通透；波浪紙偏甜感與均衡。

變化性高，適合喜歡比較不同濾紙效果的使用者。
DRIPPER GUIDE

CAFEC Flower

圓錐形｜單孔｜花瓣肋骨

內部結構

花瓣狀溝槽讓濾紙只在局部接觸杯壁，增加空氣與水流通道，減少液體停滯。

風味傾向

甜感清楚、香氣完整，兼具明亮感與厚度。

流速通常偏順，研磨不宜過粗。
結構示意圖
DRIPPER GUIDE

KONO

圓錐形｜單孔｜下半部短肋骨

內部結構

上半部濾紙較貼近杯壁，下半部才有肋骨，水流與氣體集中於底部排出。

風味傾向

甜感集中、醇厚度高、風味凝聚。

適合中心注水及日式較低擾動的沖法。
DRIPPER GUIDE

Melitta

梯形｜一孔或多孔｜淺肋骨

內部結構

梯形粉層搭配較小排水孔，濾杯本身會限制流速，操作較容易穩定。

風味傾向

苦甜平衡、口感柔和，風味較傳統。

適合初學者、家庭沖煮與中深焙咖啡。
DRIPPER GUIDE

April Dripper

平底形｜多孔｜放射結構

內部結構

寬平底使粉層均勻，多孔底部能快速排水，通常搭配專用波浪濾紙。

風味傾向

甜感乾淨、酸質柔和、風味清楚。

適合分段注水與低擾動沖法。
DRIPPER GUIDE

OREA

平底形｜多孔｜低壁結構

內部結構

低矮杯壁與大面積排水區降低阻力，部分版本可更換底部零件調整流速。

風味傾向

乾淨、甜感高、萃取效率佳。

流速快，需注意研磨度與注水量的配合。

如何選擇濾杯？

初學者：Kalita Wave 或 Melitta，流速較穩定，沖煮容錯率高。

希望表現淺焙花果香：Hario V60、CAFEC Flower 或 ORIGAMI。

喜歡甜感與醇厚：KONO 或 Kalita Wave。

喜歡研究參數與快速流速：OREA、April 或 ORIGAMI。
